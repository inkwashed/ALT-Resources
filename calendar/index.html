    Import Calendar

    Import a .ics file from Google Calendar or another calendar. Times are converted to this calendar’s time zone. Imported events use Custom times.

    This version imports single-day timed events. Recurring, all-day, overnight, and unsupported events are listed for review and skipped. Existing events are kept; matching calendar IDs are skipped on repeat imports.

      Getting started

      Plan classes from your saved school days and bell times, then export the events when you are ready.

      1

      Confirm your calendar settings

      Open Settings to confirm your detected time zone and choose what should happen if it changes later.

      2

      Set up schools and teaching dates

      Use existing Scheduler schools, or add schools, attendance dates, classes, and bell times in Settings.

      3

      Add classes from suggested periods

      Choose Regular or Irregular periods, then select a dashed suggestion to add a class. Use Add event for custom times.

      4

      Review and export

      Saved event times stay fixed when school settings change. Export an ICS snapshot when you are ready, and use the header to back up your data.

      Class Calendar currently supports single-day events. Suggested periods disappear when a saved event uses the same school, date, schedule type, and period.
