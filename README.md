# Teacher Tools / ALT Resources

A collection of browser-based tools for helping ALTs and teachers with daily tasks, class planning, and classroom activities.

The hosted site is available at [tools.jacobosinjapan.com](https://tools.jacobosinjapan.com). Its current tools can also be installed and prepared for offline use through the `/offline/` page. Teacher data remains local to the user's browser unless it is deliberately exported through Backup & restore.
