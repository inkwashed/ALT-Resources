    Class Points—

    Points are saved separately for this class by student number. Audit totals combine adjustments made within a five-minute window. Set the student count in Settings → Schools.

    Class notes

    Quick reminders and to-do lists saved separately for each class. Calendar event notes appear automatically for the matching school and class in this browser. Edit linked notes in Calendar; archive them here to hide them.

    Add note

    Use [] for a checkbox, [-] for a bullet, and [1], [2], etc. for circled numbers. Activity markers such as [G], [L], [ES], and [KS] work here too. Checked boxes appear as [x] when editing.

    Custom textbooks

    Your saved textbooks are available to all your classes. Edit a book below, or add a new one.

    Add custom textbook

    Use one line per item. Start lines with #, ##, or ### for levels 1–3. Add an icon with [G] goal, [W] watch, [L] listen, [R] read, [S] speak, [LS] Let's Sing, [LC] Let's Chant, [ST] Small Talk, [P] write, [ES] elementary-school language, [D] dictionary, or [KS] Key Sentences. Edits apply to every class using this textbook; unchanged items retain their checks.
